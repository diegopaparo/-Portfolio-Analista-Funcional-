📊 Portfolio: Análisis Funcional y Arquitectura de Sistemas

Por: Diego Paparo | Analista de Sistemas / Analista Funcional



¡Hola! Bienvenido a mi repositorio profesional. Aquí documento mi experiencia en el relevamiento, análisis, diseño arquitectónico y aseguramiento de calidad (Testing) para sistemas de información orientados a procesos de negocio.



🛠️ Competencias y Herramientas

Modelado y Arquitectura: Experiencia sólida en UML (Diagramas de Clases, Casos de Uso, Estados, Componentes y Despliegue) para estructurar sistemas transaccionales.



Gestión Ágil: Metodología Scrum, desglose de Épicas, redacción de Historias de Usuario y Criterios de Aceptación.



Ecosistema de Trabajo: Jira, Confluence, GitHub (comprensión de flujos CI/CD).



Aseguramiento de Calidad (QA): Gestión de testing con Zephyr, diseño de casos de prueba exhaustivos (caminos positivos y negativos), y redacción BDD (Behavior-Driven Development) usando Gherkin.



📁 Experiencia y Proyectos Destacados

1\. Sistema de Gestión Corporativa (Sector Construcción)

Análisis y diseño funcional para un cliente real del sector de la construcción, abarcando múltiples fases de desarrollo.



Mi rol: Analista Funcional principal durante las fases iniciales y de maduración del proyecto.



Aportes: Relevamiento profundo de requerimientos con el cliente, definición estricta de reglas de negocio, diseño de flujos operativos y arquitectura funcional del sistema base.



2\. Sistema de Gestión Integral de Servicios (AutoTech S.A.)

Diseño funcional de un sistema transaccional para la gestión de clientes, repuestos, turnos, presupuestos y órdenes de trabajo.



Mi rol: Analista Funcional y Responsable de QA.



Aportes: Creación del modelado UML inicial para cimentar el desarrollo, diseño de casos de uso centrados en la transacción principal (Reparaciones), y planificación del testing funcional para asegurar la calidad de las salidas del sistema.
